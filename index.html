The bottleneck in agentic coding usually isn't the model. It's what the agent can safely see and reach. Most of what I build is that layer, using Claude Code and the Model Context Protocol.

Built at GiveCampus

SolarWinds Observability MCP: debugging production from inside Claude Code

An MCP server that wraps the SolarWinds Observability (Papertrail) API, so Claude Code can query production logs, metrics, entities, and traces directly. Give it a request ID and it pulls every log line for that request. Give it a search and it groups the matching logs by request so the agent can follow a failure end to end. Production debugging used to mean bouncing between a log dashboard and an editor. Now it happens in one session.

Claude Code→ search_logs→ analyze_requests→ get_request_logs→ root cause
Open source

pg-redact-mcp

Lets AI agents query PostgreSQL without exposing PII. It detects sensitive columns using name heuristics and Microsoft Presidio, and masks the results before they reach the model, so john@example.com becomes j***@e***.com. Real values are revealed only with human approval. Encrypted fields can never be unmasked, and the server is read-only by default.

MCP · Python · Postgres · Presidio

CI Patrol

Watches CircleCI on a heavily parallelized suite of 80+ nodes. When a build fails, Claude reads the test output and the PR diff and classifies the failure as flaky, legitimate, or unclear. Flaky jobs rerun automatically, and engineers get a Slack DM only when the failure is real.

Claude API · CircleCI · Slack
