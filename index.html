AI-Driven Development

The bottleneck in agentic coding usually isn't the model. It's context: what the agent knows, what it remembers, and what it can reach. Most of my side work goes into that layer, built on Claude Code and the Model Context Protocol.

Context Share: handing off agent sessions across machines

A Claude Code plugin that came out of a question my team raised at our AI retreat: how do you pass context between agent sessions, across machines and teammates? One agent runs /context-save my-feature; another agent anywhere runs /context-load my-feature and continues where the first stopped. Each save is a structured bundle covering decisions and their reasoning, files touched, current state, next steps, and warnings. The server is a single Go + SQLite binary that runs on about 5 MB of RAM.

agent A→ /context-save→ Go + SQLite→ /context-load→ agent B

CI Patrol

Built for GiveCampus's heavily parallelized CircleCI suite, which runs 80+ nodes. When a build fails, Claude reads the test output and the PR diff and classifies the failure as flaky, legitimate, or unclear. Flaky jobs rerun automatically, and engineers only get a Slack DM when it's real.

ClawTalk, an iOS app on the App Store

A native client for self-hosted OpenClaw AI agents, by voice or text. Speech recognition runs on-device on the Apple Neural Engine with WhisperKit, and responses stream back as rendered markdown across multi-agent channels. The backend runs on AWS Lightsail and Bedrock, deployed with Terraform. It's open source (GitHub).

Swift · SwiftUI · WhisperKit · Bedrock

pg-redact-mcp

Lets AI agents query PostgreSQL without seeing PII. It detects sensitive columns using name heuristics and Microsoft Presidio, and masks results before they reach the model. Real values are revealed selectively, with human approval. It's read-only by default.

MCP · Python · Postgres

An MCP server for Unreal Engine with 127 tools across 16 subsystems and four transport layers. It needs no C++ plugin, so Claude can work with a UE 5.3+ project directly.
